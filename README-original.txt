NexyonCloud Paymenter Installer - RGB Professional
Made by Ziro

Features:
- Install / Uninstall / Exit menu
- Random RGB menu colors
- Animated loading indicator
- Paymenter production prompts are non-interactive
- Invalid setup details are re-prompted instead of immediately exiting
- Completed actions return to the main menu
- Admin account creation does not require a users.name column
- Existing Paymenter installations can resume
- Supports Debian 11/12 and Ubuntu 22.04/24.04

Run:
chmod +x install.sh
sudo bash install.sh
